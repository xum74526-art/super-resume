# Fictional showcase portraits

Two invented people were generated using Codex's built-in ImageGen tool on 2026-10-09 for resume template demonstrations. The JPEGs preserve the generated framing and are resized to at most 360 by 450 pixels for local embedding. `portraits.json` contains the same JPEGs as data URIs. No external images are requested at runtime.

## Female portrait prompt

Use case: photorealistic-natural. Create one realistic professional resume sample headshot of a fictional Chinese woman around age 28. It is an anonymous invented person, not a real public figure. Vertical portrait 4:5 ratio. Centered straight-on shoulders and head, ample margin above hair and both shoulders visible. Ivory blouse and charcoal tailored blazer, tidy shoulder-length black hair, natural subtle friendly expression, believable skin texture, neutral warm grey solid studio background, soft even studio light, high-quality professional career portrait. No text, no logo, no border, no collage, no watermark. This will be resized into a small resume photo demonstration; keep the face clear and entirely inside the frame.
