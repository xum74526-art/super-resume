# 后续开发路线

## 当前可以验收

- 标准 MCP 的工具发现、资源和提示词。
- JSON Resume 字段校验、非持久内容 revision、原子修改。
- 岗位关键词原文定位，覆盖中文子串和英文词边界。
- JSON 与保留字段的 Markdown 大纲导出。
- PDF / DOCX 文本导入、中文 PDF 和可编辑 Word 导出，MCP blob 及本地文件 CLI。
- 30 种精选 A4 模板、与 PDF 共用分页的 SVG 预览、本地模板选择和内容编辑工作台。
- 自包含插件、npm 打包、两种 marketplace、发布元数据和 CI。
- 0.2.1 的 Word 单页与多页视觉验收、标题跨页修复、Windows / Linux 独立包运行。
- Codex 与 Claude Code 原生 CLI 安装、启用，以及工具发现或 MCP 健康检查。

## 产品功能下一步

1. **客户端交互验收**：在加载 0.7.1 插件的 Codex / Claude Code 会话中，各完成一次“建简历 → 修改 → 选模板 → 预览 → 导出”。本地工作台的浏览器验收与宿主模型自动调用工具分别记录。复杂多栏阅读顺序与扫描件 OCR 另行迭代。
2. **经历素材库**：给每项原始事实分配稳定 ID，岗位版本引用来源；明确保留、删除和迁移规则。先定义本地存储边界，再考虑账户化服务。
3. **岗位适配质量**：由宿主模型区分必须项、加分项、否定句、年限和同义词；确定性工具返回可复核依据，不把字面覆盖当成资格或录用概率。
4. **版式完善**：0.7.1 提供 100 套精选设计与可选照片。下一步可按用户实际岗位继续扩展；旧社区模板已退出分发。
5. **公开分发验收**：确认发布身份，完成 npm 与 Registry 登记，再从公开来源安装并验收。其他客户端按协议接入，不能宣称全部客户端 UI 已验证。

## 以后需要独立设计

- 远程账户：OAuth、用户隔离、持久化、备份与导出/删除。
- 云端公开目录：HTTPS 部署、支持与隐私页面、发布者身份和平台审核。
- 自动投递：不属于当前插件，未来如果需要应作为独立、明确授权的能力。
