| 名称 / ID | 设计与用途 |
| --- | --- |
| 曜石 / modern | 深海蓝个人信息侧栏，经历正文独立；商务与管理 |

每套都支持 PDF、可编辑 Word、离线矢量 HTML。PDF 与 SVG 预览共用分页计划；Word 保留文字和表格，受字体和编辑器影响，分页不保证与 PDF 一致。HTML 包含全部页面的矢量字形，便于离线浏览；需要可选择文字时用 PDF 或 Word。检索入口为 `list_resume_templates`，可搜索中文名字、风格或职业方向；不提供未经验证的 ATS 通过率。

## 基础版式的前期研究

访问日期 2026-10-09。这些是实际设计参考来源，不能解读为全网热度排名或商业授权。

- [Resume.io 模板页](https://resume.io/resume-templates)：查看其现代双栏、对比色刊头、Creative 与 Executive 等设计方向。
- [Novorésumé 模板页](https://novoresume.com/resume-templates)：参考姓名/岗位层级、技能与经历分区的组织方式。
- [Enhancv 模板页](https://enhancv.com/resume-templates/) 和[官方 Word 模板文章](https://enhancv.com/blog/ms-word-resume-template/)：其文章称双栏是该产品用户中受欢迎的选择，这是平台自身口径。
- [Reactive Resume](https://rxresu.me/) 与[开源仓库](https://github.com/reactive-resume/reactive-resume)：查阅 Leafish、Azurill、Bronzor 的实际预览，参考信息层级和布局方法。仓库参考固定在 `references/upstream.lock.json` 所列提交。

本项目没有复制商业平台的模板素材或源代码，也未打包上述产品的照片。上表六套基础版式及新增国内风格均由本项目实现；原下载模板及许可证仅在本地 `references/retired/theme-library-0.4.1/` 保留追溯记录，不进入工作台、MCP 目录或新插件包。

## 简历内容

- 姓名、目标岗位、电话/邮箱与城市；按需要提供作品集或个人网站。
- 简短职业概述，说明岗位方向和有依据的优势。
- 工作或项目经历：职责范围、本人采取的行动、方法和可核实的结果。成果数字必须有事实依据。
- 与目标岗位相关的技能、教育背景，以及有用的证书、语言和奖项。
- 照片是可选项。未提供照片时不显示空框，也不添加年龄、性别、婚姻等无关字段。

工作台示例的姓名、机构与成果数字均为虚构，说明保存在样例 meta 中并在界面标明。不得直接套用为用户经历。

## 照片与隐私

工作台接受 JPG/PNG，本机缩放至最多 360×450 后存入 JSON 的 `basics.image`。MCP 只接受大小低于 160 KB、边长不超过 2000 像素的嵌入 PNG/JPEG；不下载远程图片、不执行 SVG。照片与简历不会上传到外部服务。JSON 总大小仍限制为 256 KiB。

## 验证

`npm run check` 检查全部 117 套 PDF/Word 的事实保留、预览分页、长文档、检索、HTML 完整页面、照片解析和主动内容拒绝。`npm run samples:generate` 创建虚构岗位样张。PDF 用 Poppler，Word 用 Documents 原始渲染器逐页检查；具体结果见 [验证记录](verification.md)。

`bluegold-classic` 使用蓝灰与金色斜切页眉、右上可选照片、左侧贯穿线、独立基本信息及求职意向、折角栏目与单栏履历。教育与技能排在工作、项目之前。日期与经历标题同排，技能名称和关键词紧凑排列；长内容自动续页，不截断事实。

仅打印用户提供的信息。标准 JSON Resume 联系方式直接进入信息区；可选标量扩展 `basics.gender`、`age`、`ethnicity`、`desiredLocation`、`expectedSalary` 分别进入基本信息或求职意向，缺失时不补值、不画照片空框。其他扩展字段仍保留；`meta` 不作为打印内容。装饰为代码重新绘制的矢量图形及无文字 Word 图片，不随插件分发参考简历或个人照片。
